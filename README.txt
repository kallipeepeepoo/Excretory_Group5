HOW TO RUN
1. Extract all files into the same folder.
2. Open the folder in Visual Studio Code.
3. Start Live Server from index.html.
4. Open the localhost address in Chrome.
5. Allow camera access when prompted.

CAMERA NOTES
- Camera access requires localhost or HTTPS.
- Stand far enough back for your shoulders and hips to be visible.
- The tracker follows visible body landmarks only. It cannot see internal organs.
- Kidney, ureter, and bladder graphics are educational overlays positioned approximately on the torso, not medical imaging or a diagnosis.
- If tracking fails, check browser camera permissions and close other applications using the webcam.

EDUCATIONAL NOTE
This presentation is for learning purposes only and is not a medical diagnostic tool.
